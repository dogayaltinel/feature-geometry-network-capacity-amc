\section{Data and Code Availability}
The dataset is used under its applicable research and redistribution conditions
and is not redistributed with the study records. The experimental record is
locked. The submission supplementary package, identified as
\texttt{feature-geometry-study-v1}, contains the study code, configuration
records, split indices, cost ledger, model checkpoints, predictions, analysis
scripts, environment lock, record schemas, table and figure generators, and
the manifest mapping reported quantities to their source records. A public URL
or DOI is not asserted here; the package identifier is the versioned access
reference supplied with the submission.
