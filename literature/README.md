# Literature workspace

This directory contains the working literature record for the Feature Geometry
Versus Network Capacity study. It is separate from the manuscript bibliography:
only records whose title, venue, year, authors, and persistent identifier have
been checked against a primary source should be promoted to `paper/refs.bib`.

Files:

- `search_log.md`: dated queries, screening rules, and verification status.
- `extraction_table.csv`: one row per screened paper and the fields relevant to
  representation, capacity, protocol, and reproducibility.
- `claims_map.csv`: candidate introduction claims and the evidence mapped to
  them.

The current table is an initial screening record, not a claim that the
literature is exhaustive. Before submission, every citation used in the paper
must be rechecked from the publisher page or the full paper.
